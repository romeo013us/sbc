# Protected promotion preflight

This draft adds read-only exact staging-run verification and checks the immutable recovery tree against trusted master verification code. The successful staged ZIP and recovery-pin jobs must belong to the same exact candidate SHA and run attempt. It does not certify all other applicable integrated CI, owner review, actor identity, environment or branch rules. The job deliberately has no contents-write permission and never invokes promotion. Before adding the protected write job, independently bind all applicable integrated checks to the exact candidate and seal, configure a dedicated release actor restricted to a protected environment, and verify server-side branch rules. Keep the existing master branch and legacy publisher until the cutover is demonstrably ready.
