# SBC Intelligence Factory V1 — NVIDIA-inspired, not NVIDIA-powered

Extends the existing Kim operating-plan read route. Nine departmental roles, five using current canonical advisory counts; four explicitly report missing evidence. No new runner, provider, model, GPU, or purchase path. Existing server-side financial, tenant, writer, consent and approval controls remain authoritative.

Reference patterns: [NeMo Agent Toolkit overview and migration guidance](https://docs.nvidia.com/nemo/agent-toolkit/latest/index.html), [NeMo Guardrails tool rails](https://docs.nvidia.com/nemo/guardrails/configure-guardrails/guardrail-catalog/tool-calling), [AI-Q](https://github.com/NVIDIA-AI-Blueprints/aiq), [Riva support matrix](https://docs.nvidia.com/deeplearning/riva/user-guide/docs/support-matrix/support-matrix.html). Assess NeMo Relay before choosing a toolkit dependency.

Phase gates:
1. Architecture: provider-neutral local contracts and source references.
2. Kim: measured current advisory computation, not distributed tracing or historical agent performance.
3. Department roles: explicit unknown evidence, existing tenant-scoped aggregate read model.
4. Governance: proposal allowlist for human review only; not a replacement for production authorization.
5. Research: offline source-record freshness/URL check; actual research acquisition and citation verification are not connected.
6. Marketing: offline seven-day readiness evaluator, exact artwork hash and history evidence; hashes cannot detect every visually similar crop. Integrate verified creative inventory and publishing receipts before operational use.
7. Speech: bounded synthetic English/Spanish word error rate evaluator; no recordings, transcription or Riva server yet. Verify consent, retention, bilingual quality, hardware and licensing before use.
8. Runtime: Node-local only; no external inference enabled. Evaluate an isolated provider adapter with verified licensing, capacity, pricing, secret handling, timeouts and zero-spend defaults before activation.

No new network, paid AI, database writes, outreach or vendor actions. Source acceptance is not production certification. Never enter customer recordings or live credentials into synthetic tests.
