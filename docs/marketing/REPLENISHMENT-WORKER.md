# Private marketing replenishment coordinator

createReplenishmentWorker(...).runCycle() joins the trusted campaign bank, existing MySQL inventory hydration, existing tenant-scoped SQLite job queue, real source review store, FFmpeg JPEG staging and existing inventory writer. The existing local renderer/runner must be operated separately. No server timer, automatic approval, public upload or social publishing is added. Default scope is sbc-marketing, feed work only, three Eastern calendar days, up to four enqueue/stage attempts per call, English copy by default (Spanish is a separately configured operator choice). Native template layouts do not implement the bank's individual artDirection narratives; review pricing/disclaimers, originality and language before approval. The worker does not automatically replace used/rejected assets or perform readback; those tasks are surfaced for operators. No new UI.

The operator must provision a private trusted filesystem root, a dedicated non-reconnecting connection owning the existing writer lock, matching tenant queue/reviews/writer, explicit role/recovery checks, authoritative campaign bank and independently approved logo SHA-256. The logo check rejects a final-component symlink, nonregular files, PNG header/dimension mismatch and wrong digest, with a bounded read; parent directories must be trusted. It is not proof of logo ownership or full PNG validity. The existing FFmpeg stage additionally decodes and checks the actual input digest. A source-approved completed job can be staged as a new inventory revision only for a missing slot, never automatically approved for final delivery. Deterministic request keys and tenant-scoped lookup prevent repeated local queue jobs; matching bytes/source are held rather than silently reused. A failure while submitting or staging halts the current coordinator instance until explicit reconciliation. The SQLite queue and MySQL writer cannot share an atomic transaction, and the process-local busy/halt flag is not durable across restarts. Reconcile durable records and private stage before recreating it. Do not use an untrusted client to supply the injected dependencies or start concurrent coordinators. Actual writer connection and database schema are not configured here.

Five local worker regressions used real SQLite job/review/media storage, real FFmpeg/FFprobe PNG/JPEG generation, and a synthetic logo and fixture campaign bank. SQL lock, inventory reader and writer responses were simulated. The prior v6559 patch regression is replaced by two behavioral checks of the current layout script and phone error handler. The JS blob identities matched current source; current HTML theme/script refs were inspected remotely and tested on the older local index with the same refs. The existing creative-intelligence CI workflow already includes the new test glob. No full hosted CI, production DDL, real SBC artwork or live posts were executed by this commit.
