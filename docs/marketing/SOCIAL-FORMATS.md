# Multi-format social staging
The existing stageSocialJpeg and buildSocialRelease functions accept a trusted optional format: square (default 1080x1080), landscape (1200x628), portrait (1080x1920). FFmpeg fits the reviewed source without cropping into the available body area and adds the pinned PNG logo footer. It does not invent content or produce native art-directed layouts. The existing source review, final SHA-256 approval, current review version, source-history rejection, private handoff and readback rules remain. Each final format requires independent exact-byte approval. The readback verifier accepts only those three size pairs; actual pixel dimensions are checked by FFprobe at staging, not by the HTTP reader. Use a separate appropriately rendered source for each layout; variations are not independent campaign concepts. Do not publish extra feed posts or bypass the authoritative creative reuse history. Portrait is a static story candidate, not a Reel or video. Platform acceptance requires live checks. The holiday CLI remains square-only; multi-format use is through the trusted existing functions. Tests use real FFmpeg and fixture review/logo data, simulated HTTP responses. No real SBC images, approvals or public uploads are produced by CI.
