# SBC OS V65.1.71 — Bilingual Sales Operations

Adds a Command Center workspace for a Mexico-based English/Spanish sales representative serving Miami businesses.

## Included
- English and Spanish opening, discovery, objection-handling, and close scripts with copy controls.
- 30-day hiring/pilot schedule and candidate scoring rubric.
- Proposed budget: $250 fixed allocation, up to $150 commissions, up to $50 tools, and $50 contingency. Planning figures only; confirm legal compensation and worker classification before hiring.
- Browser-local pilot scorecard for call attempts, conversations, qualified prospects, follow-ups, appointments, paid sales, collected revenue, and notes; JSON export.

## Data boundary
The initial UI does not write to MySQL or create CRM leads, orders, payments, or authoritative commission entries. Scorecard values remain in the current browser and do not sync between reps/devices. Verify real sales in the existing CRM/order/payment system. No calls are initiated by this module.

## Safeguards
No schema-changing SQL, payment mutation, production customer mutation, or recovery/writer-lease bypass. Existing AI voice architecture remains untouched. GitHub CI is not proof that GoDaddy production deployed or that the live screen renders correctly.

## Next integration
After verifying the deployed workspace, add tenant-aware server endpoints for rep assignment, durable call outcomes/follow-ups, and a payment-reconciled commission ledger. Reuse existing CRM/order records; test authorization and audit trails before database writes.
