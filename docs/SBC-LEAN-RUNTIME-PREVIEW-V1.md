# God Tier lean runtime preview V1

After all original full-source and canonical ZIP tests, CI emits an additional clean-directory-only lean preview. It strips conservatively unreferenced development tests and their unused npm test aliases, not all scripts. Preserve operational commands, referenced tests, relative literal dependencies, migration/recovery utilities, compiled server and receipt. The inventory is regenerated, candidate-only and not production certified. Existing release pointers and rollback packages do not change. This is literal reference analysis, not a proof of dynamic dependencies. Hosted owner/employee and diagnostic acceptance is required. Do not overlay onto an old directory; GoDaddy can retain stale files. The existing canonical startup guard rejects browser_public overlays, but does not detect every stale test overlay. The report lists every removal. No production files are deleted.
