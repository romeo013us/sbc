# SBC NVIDIA runtime and Relay lab
Separate operator lab; not part of Kim's production request path. No GPU provisioning, sandbox creation, network credentials, external inference or purchase.

- NeMo Relay: pinned 0.11.0 Python SDK on Python 3.12, official ATOF local file sink, full payload export disabled. The actual SDK wraps 18 canonical SBC advisory policy calls (nine allowed reviews and nine denied charge requests). A private temporary directory contains synthetic trace records, which are deleted after validation. CI runs with no network and a minimal environment. This proves local tracing only, not live production agent telemetry.
- OpenShell: openshell-synthetic-policy.json is an explicit restrictive policy candidate for a disposable image with only fictional data. No network rules, hard-requirement Landlock, non-root sandbox identity, no workdir inheritance, read-only application/system paths, temporary writes only. Validate exact policy with the standalone script. A schema match is not runtime enforcement. Do not reuse on a production sandbox; no secrets or production host mounts.
- NemoClaw: on an approved compatible isolated host, install a pinned reviewed release using NVIDIA guidance and onboard a supported runtime via NemoClaw itself. Do not bypass its lifecycle with direct OpenShell creation for a managed sandbox. Inspect the effective policy (including provider rules), confirm loaded revision, then test denied network/filesystem writes and non-root identity. Until observed, no autonomous agents are enabled.
- CUDA: standalone driver API capability probe (cuInit, cuDriverGetVersion, cuDeviceGetCount). Run python scripts/nvidia_runtime/sbc_runtime_lab.py cuda on the intended host. Missing driver/no device is not GPU readiness. The probe does not allocate GPU memory, execute a kernel, or verify NIM model capacity.
- No GPU or container requirements are added to GoDaddy's production Node app. Riva speech execution remains a separate isolated test requiring supported models and synthetic audio.
