# SBC V58.3 — STOREFRONT CHECKOUT ECONOMIC RELEASE

## Production additions
- Tenant-scoped `sbc_product_catalog` economic matrix.
- Fail-closed zero/unconfigured SKU cost guard.
- Dynamic 30% contribution-margin floor.
- Immutable vendor-cost / contribution-margin snapshot on accepted checkout.
- Deterministic provider-event/order idempotency; no wall-clock idempotency keys.
- Atomic checkout ledger + revenue ledger + Agent OS event-bus commit.
- `checkout.paid` wired into the existing V58.3 shard dispatcher.
- Checkout fulfillment worker uses the captured economic snapshot.
- Durable fulfillment task uniqueness by checkout ledger.
- Webhook route moved before the API 404 boundary and bound to the real MySQL pool.
- Worker compatibility facade at `workers/StorefrontCheckoutEventHandler.js`.

## No regression
The existing V58.3 ACID claim/lease worker runtime remains authoritative. The
new checkout path does not replace the shard runtime with a polling implementation.
