# SBC V58.3 — FULL WORKER CONCURRENCY / PROCESS SCALING

## Included
- ACID worker gate
- Lease-based job ownership
- Four logical worker shards
- Configurable per-shard concurrency
- Graceful SIGTERM/SIGINT draining
- cPanel-compatible standalone worker entrypoint
- PM2 ecosystem configuration for Command Center + four worker shards
- Worker health endpoint module
- Runtime metrics schema
- Claim index/schema migration
- Deterministic concurrency test

## Shards
- slot-1-core: Command Center revenue/Agent OS
- slot-2-enrichment: prospect enrichment
- slot-3-telephony: Twilio telemetry
- slot-4-fulfillment: print fulfillment

## Important
The PM2 file is an optional process supervisor configuration. It defines one
Command Center process plus four logical worker processes. It does not assume
that every GoDaddy/cPanel plan permits PM2. The same workers can be started
directly through the cPanel Node application/worker mechanism using the shard
environment variables.

No new GoDaddy environment secret is required.
