# Capture adapters (isolated integration foundation)
createCaptureAdapter accepts server-owned signature verifier, durable payment-to-tenant binding resolver, account-scoped provider readback and evidence ingestor. Never construct these dependencies from webhook data or request parameters. The signature verifier must validate the original raw bytes with the existing provider-specific HMAC implementation. The readback must use an independently configured merchant account and mode, not an account identifier echoed from a webhook. Binding must be authoritative and immutable for a given payment. Square payment.updated (completed only) and Stripe payment_intent.succeeded are supported. Other event types are not supported. This module does not authorize entitlement actions, financial totals, refunds, disputes or subscription changes; event-level deduplication is not payment-level deduplication. The current production webhook routes are unchanged. Do not activate before durable binding resolver, provider-specific transport, real signature and integration tests, schema verification, writer fencing and hosted acceptance. For ledger integration the ingest callback is a server-owned closure over ingestPaymentEvidence(authoritativePool,evidence,options).
