# SBC OS V65.0.6

## Purpose
Remove misleading legacy application-version wording from the `sbc_settings.setting_value` schema message and avoid repeating an unnecessary `ALTER TABLE` on every boot when the column is already MEDIUMTEXT or LONGTEXT.

## Safety
- Preserves the MEDIUMTEXT upgrade for smaller legacy column types.
- Leaves LONGTEXT and MEDIUMTEXT unchanged.
- Does not modify the 248-record recovery threshold.
- Does not insert, update, or delete CRM leads.
- Does not enable Revenue PLAY, outreach, Kim mutation workers, payments, or recovery unlocks.
- Does not change the database at build/package time.

## Verification scope
Run `npm run test:v6506-schema-log`, `node --check server.js`, and the existing V65.0.5 notification UI tests before deployment. This package has not been deployed to GoDaddy by this build step.
