## Read-only customer reference audit

The following query matches the table/column names in the supplied SQL dump. Run it only in the intended database and inspect the output before taking any action:

```sql
SELECT src, customer_id, customer_name, COUNT(*) AS records
FROM (
  SELECT 'orders' AS src, customer_id, customer_name FROM sbc_orders
  UNION ALL
  SELECT 'quotes' AS src, customer_id, customer_name FROM sbc_quotes
  UNION ALL
  SELECT 'renewals' AS src, customer_id, customer_name FROM sbc_renewals
) AS refs
WHERE customer_id <> ''
  AND customer_id NOT IN (SELECT id FROM sbc_customers)
GROUP BY src, customer_id, customer_name
ORDER BY customer_id;
```
