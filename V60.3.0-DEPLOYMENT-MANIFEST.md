# SBC V60.3.0 Deployment Manifest

## Release
- Version: 60.3.0
- Build: Experience OS
- Deployment target: GoDaddy Node.js / cPanel
- Secret changes: NONE
- Database: additive migration only

## New capabilities
- Customer 360 read model
- Local-first server-authoritative snapshot API
- Metadata/custom fields
- Role work queues
- Logical cells
- Kim governance trail

## Deployment sequence
1. Upload the flat ZIP contents to the existing SBC application root.
2. Do not change existing environment secrets.
3. Run the normal GoDaddy build/start process.
4. Confirm `/api/experience/health` returns version 60.3.0 for an authenticated owner session.
5. Confirm existing `/api/god-tier/health` and `/api/commercial/summary` still return successfully.
6. Review GoDaddy startup logs for MySQL errors before opening customer traffic.

## Rollback
Restore the prior known-good V60.2/V60.1.x package. V60.3 tables are additive and do not require destructive rollback.
